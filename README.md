# 东水磨立体地图

这是可独立上传到 GitHub Pages 的静态项目。当前公开快照为 `eastshuimo-atlas-2026-09-10-v8`，包含总览、11 栋楼、LG／G／F1／F2、屋顶（3层）及相互定位链接。运行时不依赖房间编辑服务或浏览器缓存。

## 本地打开

Windows 可双击 **启动地图.cmd**。也可以在本目录运行：

```sh
npm ci
npm run build
npm run preview
```

随后打开 `http://localhost:4173/#/overview`。浏览器会限制 `file://` 页面读取模块和地图数据，因此不要直接双击 `index.html`。

- `src/`：地图界面源码
- `data/map.json`：公开地图快照
- `vendor/`：随项目提供的 Three.js 与 OrbitControls
- `dist/`：构建后的纯静态成品

## 视图

- 总览：`#/overview`。显示连续建筑体块、道路、走廊、门厅、庭院和跨层交通，隐藏房间内部墙线。
- 独栋：例如 `#/building/9`。显示该楼地上空间、关联地下空间、清理后的房间、门窗、交通与内饰。
- 独层：例如 `#/floor/G`。显示该层详细结构和分区；LG 支持大分区、子分区和细分区托底切换。
- 屋顶：`#/floor/ROOF`。屋顶是独立的“3层”，覆盖房间、走廊、过道和可步行平台，只扣除核实后的天井开口。
- 房间定位：`#/floor/F1?room=房间ID`；交通定位使用 `stop=入口ID`。

总览和独栋默认展开。每层上方净空为该层层高的三倍；F2 与屋顶之间的展开净空为 10.8 米。缩合时恢复连续标高。显示范围可按楼层、楼栋、分区、子分区和连续体块控制；屋顶、透明场地地面、内饰、标签与图例均可单独切换。

电梯使用黄色荧光。分层视图中，楼梯用红色向上、深绿色向下，并显示目标层；合层视图直接显示相邻层间的连续楼梯。天井使用贯通的蓝色微透明玻璃与黑色透明承重柱，不作为通行连接。

## 数据概况

- 公开房间：LG 256、G 241、F1 318、F2 299，共 1,114 个。
- 分区：52 个；LG 保留三级父子结构，未要求分区覆盖整层。
- 跨层交通：119 个入口、83 条相邻层连接、36 个连续交通组件。
- 屋顶与天井：11 栋楼各有独立屋顶；11 个连续天井；F2 的“窗井上空”不再误作通到屋顶的大天井。
- 内饰：1,281 个简化家具实例，包含博士生／学生工位、琴房、教室、自习讨论区、咖啡厅、休息区，以及 1 号楼 G、F1 两处行政办公室。

保留原图楼号：1 至正楼、2 中和楼、3 格物楼、5 致知楼、6 至真楼、8 至诚楼、9 知言楼、11 知远楼、12 立德楼、15 立言楼、16 立功楼。旧 B2 对应 LG，旧 B1 对应 G。共享空间使用唯一 ID，在关联独栋中按局部片段显示，在总图中只绘制一次。

## 从编辑工具更新

在房间编辑工具中维护名称、备注、对象、可见性、是否显示标注、待编辑状态和分区，然后选择“导出地图快照”。把文件导入本项目：

```sh
node scripts/import-data.mjs "导出的地图快照.json"
npm run build
```

导入器只接受公开地图快照。完整编辑备份应保留在私有目录；本项目不包含旧备注归档、隐藏后勤详情、原始 PDF／Paint 图纸或套间恢复数据。

## 精度说明

平面范围来自四份原设计图，并结合用户提供的地下范围和分区示意复核。标高采用 LG -8.8 米、G -5.2 米、F1 0 米、F2 4.5 米；对应展示层高为 3.6、5.2、4.5、3.6 米，楼板厚度 0.18 米。缺少完整剖面资料的局部高度和家具高度仍为示意。

仍有 1 个 LG 电梯入口因相邻层落入非所属范围而不虚构连接。建筑形态用于空间浏览，不是施工模型。图形风格和楼名参考[求真立体图](https://simplicialcat.github.io/Qiuzhen-map)，没有复制其代码。Three.js 与 OrbitControls 的 MIT 许可见 `vendor/LICENSE`。
